Requests

How long Lexi waits for a provider before it stops and says so. Without Stream, the whole answer must arrive within this time. With Stream, it's the longest Lexi waits with nothing arriving (before the answer starts, or between its pieces), so a long answer that keeps coming is never cut off. 0 means no limit; the default is 300 (5 minutes). The lexi command line and the Python library use the same setting (lexi config set request_timeout 120).
